# EGAS Контроль аренды

Прототип сервиса для собственников ТЦ и БЦ. Показывает реальную заполненность по договорам рядом с цифрой УК, должников с долгом в месяцах аренды, договоры на 6 и 12 месяцев и арендаторов с риском ухода

Демо: https://kirter17.github.io/egas

Данные: реестры арендаторов Меридиана, Слободы и Речного на 01.10.2026 и отчёт УК Меридиана за сентябрь 2026

ИИ: в демо режиме показана сводка, которую ИИ заранее подготовил по данным объекта. Для живой генерации нужен серверный ключ модели

Запуск локально: скачать index.html и открыть в браузере
